# Louise's Pub Quiz

A pub quiz made for Louise Baskerville, all about Colorado. The questions come in
four flavours: Denver, the Mountains, History and Wild Colorado. It's a single web page: open `index.html` in any
browser, or on an iPad. There is nothing to install.

- Three rounds of ten multiple-choice questions: hard, harder and hardest.
- Each round mixes all four categories, and each question shows which one it's from.
- After every answer you see whether you were right and a short fact about it.
- At the end of each round, and at the end of the quiz, you see the score for each
  category. The final screen lists every question with its answer.
- The answers are shuffled each time you play, and the quiz remembers where you got
  to if you close it partway through.

To change a question, edit `ROUNDS` near the top of the script in `index.html`. The
first option in each list is the right answer.
